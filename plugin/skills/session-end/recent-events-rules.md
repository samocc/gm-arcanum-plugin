# Recent Events — Summarization Rules

`recent-events.md` is **campaign memory** — what the GM reads at the start of the next session to remember the story so far. It answers "what happened?" at a plot level, not "what exactly did we do?" at a turn level. The session log is for turn-level detail.

## Rules

- **Focus on key plot points, character decisions, and important information** a GM would need to remember. Omit trivial details.
- **NO mechanical details.** No check results, no DCs, no roll numbers, no modifiers. Summarize only the in-character outcome:
  - YES: "Arjen examined the components and discovered they share an identical alloy with his Velundurr specimens, but at significantly larger scale."
  - NO: "Arjen's Investigation (26) revealed the same alloy composition..."
- **Combat: brief, outcome-only.** Name what they fought, the outcome, and any story-significant moments. No turn-by-turn, no individual attacks, no damage numbers.
  - YES: "A modified burrower attacked from a ceiling crevice. The party dispatched it quickly — it was more victim than threat. Its implant contained the first intact signal bead."
  - NO: "Xalyth spotted a modified burrower (Perception 18). Arjen caught it with Booming Blade, Xalyth hit with Scorching Ray, Torben finished it."
- **Filter OOC.** If an out-of-character discussion led to an in-character outcome, record only the outcome, not the mechanics that led to it.
- **Mature content:** High-level, non-explicit acknowledgment only.
- **Past tense.** These are recorded events — never continue the narrative.
- **Target length: 80-150 words per session.** If it reads like a session log, it's too detailed.

## Format

Append a new section header (`## Session [N]`) followed by 1-3 paragraphs of narrative summary.
