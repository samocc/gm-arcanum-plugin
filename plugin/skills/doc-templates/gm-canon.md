# GM Canon — Template

Template for gm-canon.md files. GM Canon tracks narrative threads that span multiple modules and world truths not captured elsewhere. This is a GM-only document — never shown to the player.

At campaign creation, seed this file from the template below. Populate threads from campaign-pitch (Core Arc, Secondary Arcs) and companion-guide docs (companion arc threads). During gameplay, threads are added and updated by end-of-session and module prep workflows.

---

## Template

```markdown
# GM Canon
<!-- FILLING GUIDANCE

WHAT BELONGS AS A THREAD:
A thread is something that transcends a single module — it started in one module and needs to be picked up, continued, or referenced in a different module and is not **fully** covered or detailed in campaign-summary, recent-events, world-info, or npc-directory.. Without tracking it here, the prep agent would produce a contradiction, a missed connection, or a dead thread. Threads can be campaign-spanning (Core Arc) or short-lived (a 2-3 module quest). Duration doesn't matter — scope does.

This also includes companion *arc progression* — how a companion's Motivations are advancing through gameplay.

WHAT IS NOT A THREAD:
- Self-contained encounters (beasts were just beasts, fought them, done — no forward connection to another module)
- NPC-specific details — lives in `npc-directory.md`. Meeting an NPC, having a conversation, even "we might see them again" is NPC territory, not a thread. Unless the NPC is actively involved in something that spans modules.
- Companion personality, behavior, and hooks — lives in `companion-guide.md`. The prep agent reads those separately.
- Companion relationship dynamics with the PC — lives in session-log Companion Progress, not here.
- Zone-locked details — if it only matters within the zone it was discovered in, the module prep handles it. (e.g., a zone's acoustics, local ecology, internal geography)
- Things the party didn't find — use the "falling tree test": if the party didn't engage with it, it doesn't exist / didn't happen. Don't track fallen trees nobody heard.
- Player-known events already captured in `recent-events.md`.

LABELS: Tag (Core Arc) or (Secondary Arc) ONLY if explicitly designated in campaign-pitch.md. Tag (Companion) for companion arc threads. Emergent or shorter threads get no label.

When an unlabeled thread fully resolves, remove it from this file. Labeled threads (Core Arc, Secondary Arc, Companion) are never removed — mark as resolved but keep.
-->
```
